# Microsoft 365 Mail Migration

Runbook for migrating hosted email (for example PA Vietnam) to Microsoft 365 Exchange Online using IMAP where supported.

Files:
- Microsoft-365-Mail-Migration-Runbook.pdf - field-ready implementation runbook
- Microsoft-365-Mail-Migration-Runbook.md - editable source
- templates/ - reusable migration templates

Security: never commit real mailbox passwords, admin passwords, access tokens, private keys, or customer secrets.
